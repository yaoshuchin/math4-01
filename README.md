# 國小四年級數學：一億以內的數 魔法探索樂園 (math4-01)

專為國小四年級數學「一億以內的數與位值」單元設計的魔法主題互動學習網站。

## 功能特色

1. **錢幣堆疊量感探索**：千、萬、十萬、百萬、千萬到一億的立體堆疊體積視覺化，直觀掌握十進位跳躍。
2. **互動位值板**：動態增減各個位數數值，即時顯示國字讀法與位值分析。
3. **四位一級「劃線讀數法」**：互動筆刷工具，由右至左每四位分級劃線，破解大數讀寫難題。
4. **數的大小比一比**：比位數、比最高位天平對決遊戲。
5. **捷運情境生活應用題**：結合北捷、高捷等大眾運輸載客量數據，活化生活化讀寫數。
6. **10 題綜合闖關測驗**：即時回饋、評分稱號結算與 canvas-confetti 慶祝紙花特效。
